# Как наполнить и запустить сайт

## Музыка

1. Положите MP3-файлы в `assets/music/`.
2. Положите обложки в `assets/covers/`.
3. Откройте `data/songs.json` и для каждого трека измените `title`, `artist`, `src`, `cover` и `note`.

Пример: если файл называется `our-song.mp3`, укажите `"src": "assets/music/our-song.mp3"`. На главной странице будет большой плеер, на остальных страницах — компактный внизу справа. Браузер разрешает запуск звука только после нажатия на кнопку воспроизведения.

## Фотографии и истории

Есть два способа:

1. **Постоянные общие воспоминания.** Положите файлы в `assets/memories/` и редактируйте `data/memories.json`. Это содержимое увидит каждый, кому вы отправите папку сайта.
2. **Личная мини-галерея.** На странице «Воспоминания» внизу есть форма «Добавить новый момент». Фото автоматически сожмётся, а дата, подпись и история появятся в галерее, календаре и звёздном небе. Эти материалы хранятся только в браузере устройства, с которого их добавили.

## Тексты

- Главный экран: `index.html`.
- Воспоминания: `data/memories.json`.
- Письма: `data/letters.json`.
- Вопросы игр, причины любви, сюрпризы и финальное письмо: `js/games.js` и `js/main.js`.
- Ссылка на закрытый ролик: `pages/for-you.html`, атрибут `href` у ссылки `data-final-video`.

## Запуск

На Mac самый простой вариант — дважды нажмите `start-site.command`: браузер сам откроет актуальную версию по адресу `http://localhost:8765`. Окно Терминала нужно оставить открытым, пока вы смотрите сайт.

Либо для корректной загрузки JSON, видео и музыки запустите локальный сервер вручную:

```bash
cd "/Users/saveliy/Downloads/romantic_site_package 10"
python3 -m http.server 8765
```

Затем откройте `http://localhost:8765` в браузере. Остановить сервер можно сочетанием `Ctrl+C` в Терминале.

## Важно о «галерее для двоих»

У статичного сайта нет собственного сервера, поэтому форма загрузки не синхронизирует новые фотографии между разными телефонами или ноутбуками. Чтобы сделать настоящую совместную галерею с аккаунтами и синхронизацией, нужен отдельный бэкенд или облачная база данных.
