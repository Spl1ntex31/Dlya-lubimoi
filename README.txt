РОМАНТИЧЕСКИЙ САЙТ — КАК ДОБАВИТЬ СВОИ ФАЙЛЫ

1. Открывай index.html в браузере.
2. В папку important положи:
   - ded_mem.mp4 — видео-мем для кнопки «НЕТ»;
   - photo1.jpg, photo2.jpg, ... photo10.jpg — фотографии для десяти сердечек.
3. В папку background положи:
   - music.mp3 — фоновую песню;
   - 67.mp3 — отдельный звук для момента 67%;
   - cat1.png, cat2.png, cat3.png, cat4.png, cat5.png — котики на прозрачном фоне.
4. В index.html найди const YOUTUBE_LINK и замени https://youtube.com/ на свою ссылку на подарок.

Музыка запускается при первом взаимодействии с сайтом: большинство браузеров блокирует
автовоспроизведение звука до первого нажатия. На коротких экранах ноутбуков панель музыки
перемещается наверх, чтобы не закрывать содержимое страницы.

Изображения, видео и аудио в архив не включены — добавь свои файлы с указанными именами.
Для шрифтов, иконок, QR-кода и конфетти нужен интернет.
