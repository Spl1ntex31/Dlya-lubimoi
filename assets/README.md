# Куда добавлять свои материалы

Создайте папки рядом с этим файлом: `memories`, `music`, `covers` и `videos`.

- `assets/memories/` — фотографии воспоминаний, например `first-walk.jpg`.
- `assets/videos/` — короткие видео `.mp4`.
- `assets/music/` — ваши композиции `.mp3`.
- `assets/covers/` — обложки треков `.jpg` или `.png`.

Пути к готовым файлам меняются в `data/memories.json` и `data/songs.json`. Не переименовывайте JSON-файлы: это «панель данных» сайта.

Личная форма «Добавить новый момент» на странице «Воспоминания» сжимает и сохраняет загруженные фотографии в браузере текущего устройства. Чтобы видеть одну и ту же общую галерею на двух телефонах/ноутбуках, потребуется сервер или облачное хранилище; статичный сайт сам по себе не умеет синхронизировать пользовательские загрузки.
